Thompson’s construction

Each AST node becomes a fragment with one start and one accept state. Literal: one edge. Concatenation: ε from left accept to right start. Union: new start/accept with ε branches. Star: ε entry, exit, skip and loop-back edges. + has no skip edge; ? has no loop-back.

Subset construction

Start with ε-closure(start). For each DFA state S and symbol a compute T = ε-closure(move(S,a)). Every new non-empty T becomes a DFA state; a state is accepting if it contains an NFA accept state. See the Subset tab.

DFA minimization

Remove unreachable states, add a dead state, start with {accepting},{non-accepting} and split blocks whose states reach different blocks on some symbol until stable. Each final block is one state. See Partitions.

State elimination

Add new start S and accept F, then remove states one by one: new edge R(p,r) | R(p,q) R(q,q)* R(q,r). The last S→F label is the regex, simplified (ε-identity, (a*)*=a*, ε|x = x?).

Syntax cheat-sheet

ab concat · a|b union · (…) group · * + ? repeat · ε or empty branch (a|) · [a-c] class · \* escape. Not supported: back-references, anchors, {n,m}.

Worked example

(a|b)*abb → 14-state ε-NFA → 5-state DFA (A…E) → 4-state minimal DFA, because states A and C… merge when they behave identically. Try the string aabb in the Simulator.
